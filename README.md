# HC initiation during norepinephrine support

**研究目标：在感染评估记录支持、正在使用去甲肾上腺素（NE）的成人ICU患者中，比较当前启动氢化可的松（HC）与当前暂不启动、随后接受通常照护的院内死亡风险。**

本仓库管理HC研究的代码、执行清单与研究决定。现有MIMIC实际首剂主分析保留；新增MIMIC医嘱分析与eICU医嘱分析各自重新定义资格、起点、风险集和调整。不是“曾用过HC与从未用过HC”，也不是完整疗程、固定延迟政策或已确认全部患者符合Sepsis-3感染性休克。

私有远端：[Sheldon0106/hc-initiation-tte](https://github.com/Sheldon0106/hc-initiation-tte)。代码与计划在此版本管理，受限数据及患者级产物只留本地。

当前阶段：**MIMIC实际首剂、独立MIMIC医嘱和eICU医嘱三种比较均有实际结果；保持分别报告，完成本轮不确定性与敏感性分析，进入稿件整合。** 代码能够运行不等于已验证因果识别；结果方向一致也不是阶段通过条件。

## 为什么这样规划

|当前依据|必须先做的工作|避免走回的弯路|
|---|---|---|
|eICU medication明确是医嘱，并不保证实际执行；MIMIC有POE、处方及eMAR三种时刻 [1,2]|先在MIMIC内部建立独立医嘱队列，再看与实际首剂的联系|把时间字段改名后直接拼接两库|
|旧MIMIC处方缓存只覆盖约4,350次原风险集住院，而成人NE来源约15,010次住院|对旧范围之外的住院补取必要医嘱资料|以后来实际启动者及其旧对照决定新的医嘱研究资格|
|两库点估计方向不同，且此前结果均已看过|固定比较问题与全部分析口径，先解释人群、来源和时间差异|调窗口、亚组或模型以追求相同方向或显著性|
|整体SMD较小，但部分医院NE剂量缺失、部分局部风险集支持弱|报告医院记录结构、局部支持及选择性；分别说明可测与不可测混杂|只展示整体平衡后宣布识别成立|
|Rajendran等有双库合并、处方来源的先例，但其CEDAR另作验证 [3]|借鉴来源协调与分别评价，再判断是否有汇总意义|将“使用两个库”本身当作创新或外部验证|
|TARGET要求交代目标试验、数据映射与识别假设 [4]|以实际代码完成试验映射与解释边界|只靠标题或格式把观察性关联升级为治疗建议|

#### 未测混杂：有限的定量情景

令U表示索引前尚未记录、可能影响开药选择的临床状态，且在两组均有定义；δ为启动者与已加权对照中U的比例差，γ₀为在暂不启动HC条件下U关联的死亡风险差。在已测协变量层内γ₀与δ均恒定的简化ATT模型中，偏倚为γ₀×δ；情景RD等于观察RD减去该偏倚。[VanderWeele与Arah的偏倚公式](https://doi.org/10.1097/EDE.0b013e3181f74493)为此提供一般框架。
本轮在续跑前固定γ₀=10、20、30个百分点，δ=−30、−20、−10、0、10、20、30个百分点，全部组合保留。它们是研究者情景，不是从HC用途或限制治疗资料估计的比例；正负失衡均评估。对固定偏倚平移抽样区间，没有为这些未知参数捏造概率分布。

|γ₀ × δ|δ=10个百分点|δ=20个百分点|δ=30个百分点|
|---|---:|---:|---:|
|γ₀=10个百分点|1个百分点|2个百分点|3个百分点|
|γ₀=20个百分点|2个百分点|4个百分点|6个百分点|
|γ₀=30个百分点|3个百分点|6个百分点|9个百分点|

δ为负时，上表偏倚取相反符号。下面并列同一固定示例γ₀=20个百分点、δ=±20个百分点；完整21格情景由代码保存在现有私有缓存中。

|主视角|δ=+20个百分点：情景RD〔条件区间〕|δ=−20个百分点：情景RD〔条件区间〕|
|---|---:|---:|
|MIMIC实际首剂|-6.47〔-11.72, -1.13〕|+1.53〔-3.72, +6.87〕|
|MIMIC新医嘱|-2.48〔-8.62, +2.93〕|+5.52〔-0.62, +10.93〕|
|eICU医嘱|+3.64〔-0.21, +7.70〕|+11.64〔+7.79, +15.70〕|

该情景计算没有证明U存在或达到某个强度，也不能修复医嘱、实际执行和临床用途的错分。其用途是说明剩余混杂在什么量级上会改变解释，不从情景中选择最有利的结果。
